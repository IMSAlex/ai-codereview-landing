Публичная оферта (Договор) на оказание услуг AI Code Reviewer

Редакция от 25 мая 2026 г.

1. Общие положения

1.1. Настоящий документ является официальным предложением (публичной офертой) Самозанятого Молева Александра Юрьевича, ИНН 504219676915 (далее — «Исполнитель») заключить договор на оказание услуг по предоставлению доступа к сервису автоматического код-ревью «AI Code Reviewer» (далее — «Сервис»).

1.2. Акцептом (принятием) оферты считается оплата услуг Пользователем на сайте https://imsalex.github.io/ai-codereview-landing/.

2. Предмет договора

2.1. Исполнитель предоставляет Пользователю доступ к Сервису — автоматическому AI-инструменту для анализа исходного кода в Pull Request на платформе GitHub. Сервис генерирует рекомендации по стилю, безопасности и логике кода на русском языке.

2.2. Тарифы и лимиты (количество проверок в месяц) указаны на странице Тарифы.

3. Порядок оказания услуг

3.1. После оплаты Пользователь получает лицензионный ключ и инструкцию по подключению Сервиса к своему GitHub-репозиторию.

3.2. Сервис может работать в двух режимах:

  • Self-Hosted (на оборудовании Пользователя): код Пользователя обрабатывается локально на его собственном оборудовании и не передаётся Исполнителю;
  • Облачный (на сервере Исполнителя): код Пользователя передаётся для анализа на выделенный сервер Исполнителя, находящийся на территории РФ. Исполнитель обязуется не сохранять, не накапливать и не передавать полученный исходный код третьим лицам.

      • Конкретный режим работы определяется Пользователем при подключении Сервиса или согласовывается сторонами дополнительно.

      4. Права и обязанности сторон

      4.1. Исполнитель обязуется обеспечить работоспособность лицензионного сервера и корректное списание квот согласно выбранному тарифу.

      4.2. Пользователь обязуется не передавать лицензионный ключ третьим лицам.

      5. Ответственность сторон и ограничение ответственности

      5.1. Сервис предоставляется по принципу «как есть» (as is). Исполнитель не несёт ответственности за:

      • Решения, принятые Пользователем на основе рекомендаций AI;
      • Любой ущерб, связанный с использованием или невозможностью использования Сервиса;
      • Ошибки в коде, пропущенные AI-ревьюером.

      5.2. Пользователь осознаёт, что AI-инструмент носит рекомендательный характер и не заменяет профессиональное код-ревью человеком. Все предложенные изменения должны проверяться Пользователем перед внедрением.

      6. Конфиденциальность

      6.1. При использовании Self-Hosted режима Исполнитель не получает доступа к исходному коду Пользователя. При использовании облачного режима Исполнитель получает доступ к коду исключительно в целях автоматизированного анализа и обязуется не сохранять его после завершения проверки, а также не передавать третьим лицам. Лицензионный сервер в обоих режимах обрабатывает только метаданные (номер PR, название репозитория) для учёта квот.
