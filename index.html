Часто задаваемые вопросы

Куда отправляется мой код?

Вы сами выбираете, где обрабатывать код. В стандартном режиме он обрабатывается на нашем выделенном сервере в России и не сохраняется. Для проектов с повышенными требованиями к безопасности мы предоставляем Docker-образ — в этом случае код вообще не покидает ваш контур.

Какие языки поддерживаются?

Сейчас Python. JavaScript, TypeScript и Go — по запросам первых клиентов. Список расширяется.

Что нужно для установки?

Для быстрого старта — ничего, кроме добавления GitHub Actions воркфлоу. Для self-hosted режима потребуется GPU-сервер и Docker.

Можно ли использовать в коммерческих проектах?

Да, конечно. У нас есть тарифы для команд и индивидуальных разработчиков. Для крупных компаний предлагаем self-hosted решение с полным контролем над данными.
